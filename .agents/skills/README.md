# Skills

Store each skill in its own directory: `.agents/skills/<name>/SKILL.md`.
Use descriptive names with lowercase letters and hyphens.

`SKILL.md` uses the Agent Skills format with YAML frontmatter containing `name`
and `description`. Describe when to use the skill and the steps to perform the
task. Store supporting resources in the skill's directory and link to them.

## Available skills

| Skill | When to use it |
| --- | --- |
| [plan-task](plan-task/SKILL.md) | Create or refine a numbered task plan, using plan branches and PLAN PR titles; track questions and confirmed decisions. |
| [implement-plan](implement-plan/SKILL.md) | Implement a plan selected by title, path, or number on a branch using its agreed implementation type, verify the work, and update plan progress/status. |
