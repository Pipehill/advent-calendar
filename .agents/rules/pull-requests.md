# Pull request rules

When creating or updating a pull request, prefix its title with the task type
in uppercase square brackets, followed by a colon and a space:

`[TYPE]: Short English description`

| Task type | Title prefix |
| --- | --- |
| chore | `[CHORE]:` |
| feature | `[FEATURE]:` |
| bugfix | `[BUGFIX]:` |
| documentation | `[DOCUMENTATION]:` |
| ci | `[CI]:` |

For other task types, use the same format with the uppercase task type.
Use the type established for the task. If it has not been established, ask the
user rather than choosing one silently.

Example: `[CHORE]: Set up agent resources and task planning workflow`.
