# Calendar background artwork

Four original illustrations were generated with the built-in `image_gen` tool
on 2026-11-01 for plan 00015. They are served locally under
`public/images/calendars/`. Stable API selection identifiers are `woodland`,
`sleigh`, `playtime` and `aurora`. Each full image is 1536 x 1024; matching
`-thumb.jpg` choices are 384 x 256. JPEG encoding uses quality 88 and thumbnails
use bicubic downscaling. No remote URLs or runtime image service are required.

All prompts requested original landscape artwork without words, numbers, logos,
watermarks or UI, with calm central space for separate opaque HTML door buttons.
The artwork was inspected before integration; labels, focus and content remain
ordinary localized HTML rather than image text.

| Identifier | Generation direction |
| --- | --- |
| `woodland` | Cute storybook woodland foxes, rabbits and squirrels preparing Christmas in a snowy Norwegian forest, lanterns, fir trees and presents; warm amber and evergreen gouache/watercolor. |
| `sleigh` | Action-filled sleigh adventure through Norwegian mountains, cheerful child and friendly reindeer, curving snowy trail, ribbons and warm village lights; dynamic polished storybook illustration. |
| `playtime` | Very young children: soft rounded snowmen, friendly bunny and teddy bear, small decorated tree and large presents; bright, simple pastel paper-cut/gouache illustration. |
| `aurora` | Older children: atmospheric winter adventure with green/violet northern lights, blue mountains, frozen fjord, warm cabins and tiny explorer silhouette; cinematic painted illustration. |

Door controls use translucent pale surfaces and dark numerals with a small local
backing over every scene. Smaller chronological doors and a scattered Random
layout expose more of the artwork. Preview
content is rendered as plain text with preserved line breaks in a separate panel.
